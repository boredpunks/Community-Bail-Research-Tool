---
name: Search progress visibility
description: Product requirement for live search status and activity details.
---

Show users the actual work as it happens: current stage, request and processing updates, timestamps, durations, and useful source messages. Do not show a disclaimer about why there is no precise completion timer; keep the interface focused on observed progress.

**Why:** the user explicitly said the goal is to make the work's progress visible and approved showing raw source messages when they help explain what is happening.

**How to apply:** when improving search progress, prioritize concrete activity records and measured durations over speculative ETAs or explanatory caveats.
