name: Independent research-stage acceptance
description: Calendar discovery, document transport, local extraction, filtering and pending saving require separate evidence.
---

Do not make an authorized calendar-only demonstration wait for PDF downloads
or real-document regressions. Retain and display validated calendar rows,
their source-provided document actions, and truthful coverage when document
retrieval is unavailable.

**Why:** The user explicitly corrected the regression-PDF-first dependency:
one denied document request must not be represented as failed calendar
submission or prevent useful discovery results from being available.

**How to apply:** Report calendar discovery, live document access, local PDF
extraction, filtering, and pending saving separately. Preserve source stops and
consumed permits; obtain fresh scoped authorization where required, without
treating another stage's success as permission or proof.

Establish document-link and client/session provenance before another live
document attempt. A constructed URL is not a captured source action, and
missing source-generated parameters must not be invented.

**Why:** The user specifically required distinguishing constructed URLs,
current source-provided links, successful external-browser evidence, and the
integrated client's actual request path.

**How to apply:** Use complete source-provided actions with parameters
preserved, but never expose opaque parameters, cookies, tokens, or personal
records in reports. Locally supplied PDFs can verify extraction and page
references; label that as local verification, never live retrieval acceptance.
