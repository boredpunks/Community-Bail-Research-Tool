---
name: Shared search visibility
description: Workspace-password access determines who can view earlier searches versus manage them.
---

Earlier bail searches and their results are visible to anyone who has passed the shared workspace password. Only the session that created a search can resume it; any workspace user can clear eligible search history across sessions or save eligible results to shared Candidates.

**Why:** The workspace is shared across sessions, and the user asked for Clear to apply across the whole workspace while keeping resume controls creator-owned.

**How to apply:** Keep search-history and result-status reads available across authenticated workspace sessions; enforce creator-session checks for resume, allow any workspace user to clear eligible searches, and preserve shared Review and Candidates items.
