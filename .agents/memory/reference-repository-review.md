For this project, do not dismiss a same-portal reference merely because it uses a different county or search mode. Inspect its actual navigation, search submission, result parsing, document downloading, and PDF extraction before judging applicability.

**Why:** The user corrected an assessment that understated the relevance of a supplied project searching the same court website, asking for a closer reading.

**How to apply:** Distinguish direct same-website relevance from present-day compatibility. Explain concrete selectors, routes, session behavior, and parsing assumptions that need adaptation rather than treating the absence of a ready-made current adapter as a reason to ignore the reference.
