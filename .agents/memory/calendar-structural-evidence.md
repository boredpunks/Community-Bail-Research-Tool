---
name: Calendar structural evidence
description: Distinguish reproduced parser defects from proven historical calendar failure causes.
---

Never infer competing document actions from raw anchor counts, or attribute a
historical malformed-table failure solely to an independently reproduced parser
defect. Historical reports without branch reasons leave that cause unknown.

**Why:** The user requires implementation evidence and explicitly distinguishes
offline defect reproduction from attribution of the retained calendar failure.

**How to apply:** Preserve historical reports. Report what their diagnostics
actually establish. When more source evidence is necessary, request the smallest
authorized calendar-only observation with unchanged scope and attributable
reasons/counts; keep document readiness and publishing as separate gates.
