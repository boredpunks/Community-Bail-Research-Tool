=== 1. WHAT THIS PROJECT IS ===
Community Bail Research Tool. It helps community volunteers find and accurately describe PUBLIC bail information from public Pennsylvania court sources (the UJS web portal, Allegheny County). It does not make funding decisions, does not recommend any action, does not decide who is eligible for anything, and does not replace human verification. It never invents docket entries, cases, hearings or bail amounts. Fixtures exist only in tests.

=== 2. VOCABULARY (binding definitions) ===
- Search parameters: the calendar search the owner selects: court office, event type, courtroom, start date, end date.
- Calendar row: one row of the court calendar returned by that search. It names a docket number, event type, event date and time, and courtroom.
- Docket sheet: the public PDF for one docket, fetched from a link taken from a calendar row.
- Discovery candidate: PLAIN-TEXT information, extracted from a docket sheet, for a docket whose calendar row matched the search parameters. It contains ONLY these fields: docket number; court level (Common Pleas or MDJ); calendar event type, event date, event time and courtroom (from the calendar row); bail type; bail amount in dollars (only if a monetary amount is printed in a labeled bail row); percentage condition if printed; bail posted state (shown posted / not shown / unknown); bail order date; source page number; the exact quoted bail row text; document SHA-256; retrieval timestamp; method id. Nothing else: no party names, dates of birth, addresses, charge narrative, or other text from the PDF.
- "Denied", "Nonmonetary", "Recognizance" with $0.00 means NO MONETARY BAIL RECORDED. It is never a $0 bail amount and never counts as "low stated monetary bail".
- If bail association is ambiguous, report AMBIGUOUS. Never guess.
- Allowed phrase: "low stated monetary bail". Banned words in any UI text, report or export: bargain, payable, eligible, recommended, good candidate.
- Every discovery card shows this exact sentence: "This is a discovery result, not a recommendation. The stated bail amount does not establish the amount required for release, current custody, absence of other holds, or eligibility for assistance."
