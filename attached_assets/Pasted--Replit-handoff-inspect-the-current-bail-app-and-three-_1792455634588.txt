## 8. Perplexity’s concrete parser findings

These findings came from inspection of the integration branch’s:

```text
artifacts/api-server/src/ujs/evidence.py
```

Verify that they still apply to the current checkout.

### Finding A: normalization happens after raw-link deduplication

The inspected parser collects distinct raw href strings, normalizes them, then treats more than one normalized candidate as malformed.

Consequently, a relative URL and an absolute URL can become the same final URL but still count as two candidates.

The proposed narrow correction is:

```python
matching = list(
    dict.fromkeys(href for href in matching if href)
)
```

This collapses equivalent normalized representations while retaining distinct action parameters as distinct candidates.

### Finding B: candidate path validation is broader than transport validation

The inspected `exact_docket_link()` accepts same-source, identity-matching URLs without restricting them to docket-sheet report paths.

The downstream `source_protocol.py` permits:

```text
/Report/CpDocketSheet
/Report/MdjDocketSheet
```

The proposed narrow correction is to align document-candidate selection with those report types.

Court-summary links must remain distinguishable from docket-sheet links.

### What Perplexity actually verified

An isolated reproduction confirmed:

- Relative and absolute aliases can produce two identical normalized candidates.
- Deduplicating normalized candidates reduces those aliases to one.
- The original predicate accepts a non-document path with a matching docket query.
- Different opaque action parameters remain different after exact-string deduplication.

A patch-context check passed against an isolated file containing the inspected source contexts.

### What remains unproven

- Neither defect has been established as the cause of the retained 38-row failure.
- The full parser and application suite were not run by Perplexity.
- No repository changes were committed by Perplexity.
- No court requests were made by Perplexity.
- The generated patch was not applied to the Replit workspace.

If the patch and reproduction report are attached, inspect them. If not, the findings above are sufficient to investigate; do not assume the patch has already landed.
