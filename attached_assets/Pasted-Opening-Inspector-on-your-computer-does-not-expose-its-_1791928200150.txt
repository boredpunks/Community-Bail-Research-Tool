## 1. Capture the actual elements from your open page

With the page showing the Calendar Event form and Allegheny selected:

1. Open DevTools’ Console tab.
2. Review the script below.
3. Run it.
4. Copy the JSON it prints and paste it here or directly into Replit.

If your browser blocks pasting into the console, do not disable its protection blindly. You can instead use Elements to copy the relevant form’s outer HTML.

This script only reads the page. It does not select options, click buttons, send requests, read cookies, or collect browser storage. It deliberately excludes input values and link destinations because those can contain case details or session-related information. Dropdown options and selected dropdown values are included.

```javascript
(() => {
  const clean = value =>
    String(value ?? "").replace(/\s+/g, " ").trim();

  const visible = el => {
    const style = getComputedStyle(el);
    return el.getClientRects().length > 0 &&
      style.display !== "none" &&
      style.visibility !== "hidden";
  };

  const labelFor = el => {
    const explicit = Array.from(el.labels ?? [])
      .map(label => clean(label.textContent))
      .filter(Boolean);

    const labelledBy = clean(el.getAttribute("aria-labelledby"))
      .split(" ")
      .filter(Boolean)
      .map(id => clean(document.getElementById(id)?.textContent))
      .filter(Boolean);

    return [...new Set([
      ...explicit,
      ...labelledBy,
      clean(el.getAttribute("aria-label"))
    ].filter(Boolean))];
  };

  const controls = Array.from(document.querySelectorAll(
    "select, input, textarea, button, [role='combobox']"
  )).filter(el =>
    visible(el) && el.getAttribute("type") !== "hidden"
  ).map((el, index) => {
    const tag = el.tagName.toLowerCase();

    const result = {
      index,
      tag,
      type: el.getAttribute("type"),
      id: el.id || null,
      name: el.getAttribute("name"),
      role: el.getAttribute("role"),
      labels: labelFor(el),
      disabled: Boolean(el.disabled),
      required: Boolean(el.required),
      ariaDisabled: el.getAttribute("aria-disabled"),
      ariaRequired: el.getAttribute("aria-required"),
      ariaControls: el.getAttribute("aria-controls"),
      placeholder: el.getAttribute("placeholder"),
      min: el.getAttribute("min"),
      max: el.getAttribute("max"),
      pattern: el.getAttribute("pattern"),
      formId: el.form?.id || null
    };

    if (tag === "select") {
      result.selectedIndex = el.selectedIndex;
      result.selectedValue = el.value;
      result.options = Array.from(el.options).map(option => ({
        text: clean(option.textContent),
        value: option.value,
        selected: option.selected,
        disabled: option.disabled
      }));
    }

    if (["checkbox", "radio"].includes(el.type)) {
      result.checked = el.checked;
    }

    if (
      tag === "button" ||
      (tag === "input" && ["submit", "button", "reset"].includes(el.type))
    ) {
      result.buttonText = clean(
        tag === "button" ? el.textContent : el.value
      );
    }

    return result;
  });

  const payload = {
    capturedAt: new Date().toISOString(),
    page: location.origin + location.pathname,
    title: document.title,
    frames: Array.from(document.querySelectorAll("iframe")).map(frame => ({
      id: frame.id || null,
      name: frame.name || null,
      title: frame.title || null
    })),
    controls
  };

  const json = JSON.stringify(payload, null, 2);
  console.log(json);
  return json;
})();
```

I have not executed this script against the portal. It is a capture aid, not a tested portal integration. It inspects the current document; controls inside frames or shadow roots may require separate inspection. Custom widgets may also need an additional capture while expanded.

#### M. Research-data limitations

The portal warns that recent court-office entries may not immediately appear and disclaims accuracy and completeness. Retrieval time is not the same as the record’s last-update time.[21]

The portal says docket information is not a substitute for a Pennsylvania State Police criminal-history background check.[21]

Public docket accessibility can end when records are disposed of under applicable retention rules. Absence from this public search is not proof that a case never existed.[21]

Philadelphia matters can have related MC and CP docket numbers concerning the same incident or offenses. The portal points to the cross court docket number field for identifying related records. Do not count every docket number as an unrelated incident.[21]

Historical migration was incomplete. Describe datasets as records retrieved from the portal under stated criteria—not automatically as all cases in the jurisdiction.[21]

Do not infer current incarceration, unpaid bail, release eligibility, or assistance eligibility solely from an event label or case status.
