## What I found in the code

### 1. The calendar parser makes very specific layout assumptions

In `artifacts/api-server/src/ujs/evidence.py`, `CalendarResults` expects:

- A table with the exact ID `caseSearchResultGrid`.
- Particular headers at fixed column positions.
- Docket numbers in column 2, court office in column 10, event type in column 14, and event date in column 16.
- A document link beginning exactly with `/Report/CpDocketSheet?`.
- A recognizable document link on every non-header row.

Those assumptions may match a supported layout, but they need source-backed verification. A presentation row, an empty-state row, an absolute document URL, or a different link mechanism would not satisfy this parser.

That does not mean the checks should be removed. It means the engine must distinguish those cases instead of treating all of them as malformed case records.

### 2. The retained structural evidence already points to another unresolved issue

The execution documentation records an earlier response with:

- One result table.
- Nineteen header cells matching the bounded header checks.
- One non-header presentation row.
- Zero recognized docket-document links.
- No parser execution because the console gate stopped it.

That is useful evidence. But it is not enough to tell whether the row was an empty-state message, a data row using an unsupported link layout, or something else.

Even if the console problem disappeared, the parser could encounter another stop immediately afterward. We should resolve that response-layout question alongside console correlation—not discover it through another full attempt.

### 3. The bail extractor exists, but it is deliberately narrow

`extract_bail()` already checks document identity and parses a specific bail-table text layout. It rejects unsupported rows, ambiguous financial values, and percentage/deposit-bearing layouts rather than guessing.

That is a reasonable starting point. But code existing is not proof that the current document flow reaches it or that representative source documents pass it.
